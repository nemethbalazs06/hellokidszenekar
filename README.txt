# Hello Kids – weboldal

Ez egy teljesen statikus, mobilbarát bemutatkozó oldal.
- `index.html` – oldal tartalma
- `styles.css` – megjelenés
- `script.js` – mobilmenü és ajánlatkérő e-mail
- `logo.png` – a Hello Kids logó

## Élesítés
A weboldal ingyenesen publikálható például GitHub Pages-en.
Saját domain külön költség lehet.

## Amit még ki kell cserélni
1. Valódi zenekari fotók
2. YouTube / Instagram / Facebook linkek
3. Telefonszám és e-mail cím
4. Valódi repertoár
5. Az ajánlatkérő e-mail címe
